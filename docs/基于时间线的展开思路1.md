# 从 Timeline 直接展开到动作层：逐层榨取策略

看了你的简·爱 Phase 1 数据，质量非常好。24个子时期，粒度从"单日事件"到"数年跨度"差异很大，这直接决定了提取策略。

## 核心思路：中间插一层"场景/节拍"

Timeline 和动作之间，缺一个自然的中间层级：

```
life_stage（5个）
  └─ sub_period（24个）      ← 你现在在这里
       └─ scene / beat（?个）  ← 需要补的中间层
            └─ action（目标）
```

**为什么不直接从 sub_period 提取动作？** 因为粒度差异太大：

```
"幼年寄居·被排斥的孤儿"  → 跨8年，直接问动作会只得到最显著的几个
"红房子事件与觉醒反抗"    → 单日单场景，可以直接挖到动作粒度
"改革后的平静求学"        → 跨5年，大量日常被LLM的显著性偏差吃掉
```

所以核心策略是——**先让LLM把每个 sub_period 展开为有序的场景/节拍序列，再从每个场景中提取全量动作**。对于已经是单场景的 sub_period，则跳过展开，直接提取。

---

## Phase 2A：场景展开（Scene Decomposition）

### 关键设计：按 sub_period 的时间跨度自适应

```python
def estimate_scene_count(sub_period):
    """根据时间跨度决定场景展开策略"""
    span = sub_period.time_range
    if span <= "单日/单场景":
        return "skip"          # 直接进入动作提取
    elif span <= "数周":
        return "5-10 scenes"   # 中等展开
    elif span <= "数月":
        return "8-15 scenes"
    else:  # 数年
        return "12-20 scenes"  # 深度展开
```

### Prompt 模板：场景展开

```yaml
prompt: |
  人物：{character}
  时期：{sub_period.name}
  时间范围：{sub_period.time_range}
  处境：{sub_period.core_situation}
  起始事件：{sub_period.opening_event}
  结束事件：{sub_period.closing_event}

  请将此时期展开为一个有序的场景序列。
  每个场景是一个时空连续的、可"拍成一个镜头"的具体事件或情境。

  要求：
  1. 场景之间要覆盖此时期的完整时间线，不要跳过"平淡"的部分
  2. 不要只列标志性的高光事件，日常的、重复发生的典型情境同样要列出
     例如："某个典型的早晨""一次常规的课堂""一次普通的晚餐对话"
  3. 包括过渡性的场景——从一个状态到另一个状态之间发生了什么
  4. 对于长时间跨度的时期，用"典型场景"来代表重复模式
     例如："【反复发生】简在窗台上独自读书的下午"
  5. 每个场景标注：
     - scene_type: "singular"（一次性事件）或 "recurring"（反复发生的典型情境）
     - participants: 此场景中在场的其他人物
     - setting: 地点/环境
     - mood: 此场景的主基调

  目标数量：{target_scene_count}个场景
```

### 以"幼年寄居·被排斥的孤儿"为例，预期产出类似：

```yaml
scenes:
  - name: "【反复发生】约翰·里德的日常欺凌"
    scene_type: recurring
    participants: [约翰·里德]
    setting: 盖茨黑德庄园各处
    mood: 恐惧与屈辱
    sketch: "约翰经常无故找到简，打她、骂她、拽她头发，简通常默默忍受..."

  - name: "【反复发生】躲在窗台帘幕后独自读书"
    scene_type: recurring
    participants: [无，独处]
    setting: 早餐室窗台
    mood: 孤独中的慰藉
    sketch: "简趁里德家人不注意，缩进窗帘后面，翻阅比尤伊克的《英国禽鸟史》..."

  - name: "被排斥在圣诞节欢聚之外"
    scene_type: recurring
    participants: [里德舅妈, 三个表兄妹, 来客]
    setting: 盖茨黑德客厅
    mood: 被遗忘的伤痛
    sketch: "节日里客人来访，里德家的孩子盛装出席，简被告知'直到她学会讨人喜欢之前不许出来'..."

  - name: "女仆贝茜偶尔的温情"
    scene_type: recurring
    participants: [贝茜]
    setting: 育儿室
    mood: 微弱的温暖
    sketch: "贝茜心情好的时候会给简讲故事、唱歌谣，这是简唯一能感受到的善意..."

  - name: "简偷听到大人们谈论她的身世"
    scene_type: singular
    participants: [仆人们]
    setting: 走廊/厨房
    mood: 困惑与隐痛
    sketch: "简从仆人的闲谈中零碎地得知自己是孤儿、父亲是穷牧师..."
  
  # ... 继续展开
```

注意——**recurring 场景极其重要**。这是你对抗"LLM只记得标志性事件"这个偏差的关键武器。一个人的行为模式恰恰体现在反复发生的日常中，而不仅仅在高光瞬间里。对于训练 Role-Play-Agent 来说，recurring 场景产出的训练样本可能比 singular 场景更有价值——因为它们代表角色的**稳态行为**。

## Phase 2B：动作提取（Action Extraction）

场景展开之后，对每个场景提取全量动作。这里用**动作类型清单**作为引导框架，逼LLM在每个维度上都给出回答：

### 动作类型框架

```yaml
action_taxonomy:
  external_actions:
    verbal:        # 说了什么、对谁说、什么语气/意图
    physical:      # 身体动作、位移、姿态变化
    social:        # 与人交互——服从/反抗/讨好/回避/合作/对抗
    instrumental:  # 使用工具/物品、读写、创造、劳作
    expressive:    # 非言语的情绪表达——哭、笑、沉默、颤抖
  
  internal_actions:
    perception:    # 注意到了什么、观察到什么细节
    interpretation:# 如何理解/解读当前情境
    emotion:       # 产生了什么情绪、情绪如何变化
    recall:        # 想起了什么过去的事
    judgment:      # 对人或事做出了什么评价
    decision:      # 做了什么决定、哪怕是"决定忍耐"
    desire:        # 想要什么、渴望什么
    suppression:   # 压抑了什么冲动/情绪/想法
    self_talk:     # 对自己说了什么（内心独白）
    belief_update: # 信念是否发生了变化
```
