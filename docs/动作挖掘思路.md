# 语料合成管线：递进式人物动作榨取策略

## 核心难题

LLM有严重的**显著性偏差**——问它关于诸葛亮，它会反复给你空城计、草船借箭、出师表。你需要的是系统性地**逼**它离开高频回忆区，进入长尾知识。

关键方法论：**多轴交叉枚举**。单一维度的追问会很快撞上重复天花板，但当你把时间×关系×领域×情境做交叉时，组合爆炸会把LLM逼入非常细粒度的回忆角落。

---

## 总体管线架构

```
Phase 0: 人物元信息提取
    ↓
Phase 1: 生平骨架（你已有）
    ↓
Phase 2: 多轴展开（核心创新）
    ↓
Phase 3: 长尾榨取
    ↓
Phase 4: 内部动作专项提取
    ↓
Phase 5: 去重 + 质量筛选 + 转为 belief-observation-action 格式
```

---

## Phase 0：人物元信息提取

在做任何动作提取之前，先提取人物的**结构化元数据**，这些元数据将作为后续交叉枚举的维度值：

```yaml
prompt: |
  关于人物 {character}，请提取以下结构化信息：

  1. 身份与角色列表：此人一生中承担过哪些身份/角色/职位？
     （如：儿子、学生、军官、丈夫、父亲、皇帝、囚徒、流亡者...）

  2. 重要关系人列表：与此人有重要交互的人物有哪些？
     标注关系类型（亲人/盟友/对手/师生/上下级/恋人...）

  3. 活动领域列表：此人涉及哪些活动领域？
     （军事、政治、文学、科学、商业、宗教、艺术...）

  4. 主要活动地点列表

  5. 此人物最为人知的3-5个标志性事件（用于后续排除）
```

输出示例（曹操）：
```yaml
roles: [诗人, 军阀, 丞相, 父亲, 屯田改革者, 兵法家, 文学赞助人]
relationships:
  - {name: 荀彧, type: 谋士/知己, period: 中期}
  - {name: 袁绍, type: 少年友人→死敌, period: 早期-中期}
  - {name: 曹丕, type: 儿子/继承人, period: 中晚期}
  - {name: 关羽, type: 敬重的敌人, period: 中期}
  # ... 20-30人
domains: [军事, 政治, 文学, 农业改革, 用人, 家庭]
signature_events: [官渡之战, 赤壁之战, 挟天子以令诸侯, 杀吕伯奢]
```

**这些元数据就是后续交叉枚举的维度值。**

## Phase 1：生平骨架（时间轴）

你已经想到了这步。补充一点：不要只分大阶段，要让LLM给出**阶段内的子时期**和**转折事件**：

```yaml
prompt: |
  将 {character} 的一生划分为主要阶段，每个阶段进一步细分为子时期。
  对每个子时期，标注：
  - 时间范围
  - 此人当时的核心处境（一句话）
  - 此时期的开端触发事件和结束转折事件

  注意：不要只关注高光时刻，平淡的过渡期、低谷期、等待期同样要列出。
```

---

## Phase 2：多轴交叉展开（核心）

这是管线的关键步骤。你有了以下维度：

```
时间轴：  [阶段1, 阶段2, ..., 阶段N]
角色轴：  [角色1, 角色2, ..., 角色M]
关系轴：  [人物A, 人物B, ..., 人物K]
领域轴：  [领域1, 领域2, ..., 领域L]
```

### 策略2A：时间 × 领域 交叉

```yaml
prompt: |
  在 {character} 的 {life_stage} 阶段，
  专门聚焦于 {domain} 这个领域，
  此人做了哪些具体的事情？

  要求：
  - 列举具体动作，不是概括性评价
  - 包括成功的和失败的
  - 包括主动发起的和被迫应对的
  - 以下事件已经提取过，请不要重复：{exclusion_list}
```

示例调用：`(曹操, 早年崛起期, 文学)` → 会得到他早期的诗作、与文人的交往等，这些不是"曹操"最显著的回忆。

### 策略2B：时间 × 关系 交叉

```yaml
prompt: |
  在 {character} 的 {life_stage} 阶段，
  此人与 {related_person} 之间发生了哪些具体的交互？

  包括但不限于：
  - 面对面的对话或冲突
  - 书信/间接沟通
  - 涉及对方的决策（对方可能不在场）
  - 关系状态的变化
  - 对对方的评价或内心态度变化
```

示例调用：`(曹操, 晚年, 曹植)` → 会得到立嗣之争中的具体互动细节。

### 策略2C：时间 × 角色身份 交叉

```yaml
prompt: |
  在 {character} 的 {life_stage} 阶段，
  以其 {role_identity} 这一身份切入，
  此人做了哪些与这一身份相关的具体行动？

  注意：同一个人在同一时期可能同时扮演多个角色，
  请只关注 {role_identity} 相关的行动。
```

示例调用：`(曹操, 中年鼎盛期, 父亲)` → 得到他教育子女、安排婚姻、处理子嗣竞争等家庭面向的动作。

### 交叉枚举的规模估算

```
假设平均每人物：
  6个生命阶段 × 5个领域  = 30次调用（策略2A）
  6个生命阶段 × 8个关系人 = 48次调用（策略2B）
  6个生命阶段 × 5个角色  = 30次调用（策略2C）
  ≈ 100次交叉调用/人物

5000人物 × 100次 = 500,000次LLM调用（Phase 2）
```

这是可控的。每次调用产出5-15个动作，总计250万-750万条原始动作记录。

## Phase 3：长尾榨取

交叉枚举之后，用专门设计的prompt去挖掘常规方法遗漏的部分：

### 3A：日常与习惯

```yaml
prompt: |
  关于 {character}，已知的或可合理推断的日常习惯和例行行为有哪些？

  维度提示：
  - 起居习惯（作息、饮食偏好、穿着）
  - 工作习惯（如何处理日常事务、阅读、写作习惯）
  - 社交习惯（如何对待下属、如何接见客人）
  - 思维习惯（决策前是否会做什么固定动作、有无迷信/仪式）
  - 情绪管理习惯（生气时怎样、焦虑时怎样）
```

### 3B：失败、放弃、犹豫

```yaml
prompt: |
  关于 {character}，有哪些已知的：
  1. 明确的失败和错误决策
  2. 计划了但放弃/未完成的事情
  3. 犹豫不决的时刻
  4. 事后后悔或反思的事情
  5. 别人建议但此人拒绝的方案
  6. 此人的已知弱点、盲区或偏见在哪些事件中体现出来
```

### 3C：被动经历

```yaml
prompt: |
  {character} 有哪些重要的"被动经历"——不是此人主动做了什么，
  而是什么事发生在了此人身上，以及此人如何应对？

  包括：被背叛、遭遇天灾、生病、被俘、失去亲人、
  遭遇意外的好运、被他人的行为改变了处境等。
```

### 3D：反排除追问

这是对抗显著性偏差的直接武器：

```yaml
prompt: |
  关于 {character}，以下事件和领域已经被充分讨论过了：
  {comprehensive_exclusion_list}

  请问，在排除以上所有内容之后，关于此人你还知道什么？
  哪怕是琐碎的细节、轶事、不太确定的传说都可以。
```

可以递归执行2-3轮，每轮把新产出加入排除列表。

## Phase 4：内部动作专项提取

这一步专门针对你的训练目标——内部动作的提取。前面的步骤主要产出外部动作，这一步补充内在面：

### 4A：信念转变

```yaml
prompt: |
  {character} 一生中经历了哪些重要的信念/认知转变？

  对每个转变，描述：
  - 转变前的信念是什么
  - 什么事件/经历触发了转变
  - 转变后的新信念是什么
  - 这个转变如何影响了后续行为
```

### 4B：关键决策的内心过程

```yaml
prompt: |
  在 {character} 做出 {decision} 这个决策时，
  根据已知的历史记录和合理推断：

  1. 此人当时掌握哪些信息？缺乏哪些信息？
  2. 面前有哪些备选方案？
  3. 此人可能的内心权衡过程是怎样的？
  4. 哪些因素最终促使此人选择了这个方案？
  5. 此人对这个决策的确信程度如何？有无犹豫？
```

这一步的输出直接就接近你要的belief-observation-action格式了。

### 4C：情绪事件

```yaml
prompt: |
  {character} 在哪些时刻经历了强烈的情绪？

  请覆盖多种情绪类型：
  愤怒、恐惧、悲伤、喜悦、屈辱、骄傲、嫉妒、感动、
  绝望、释然、愧疚、复仇欲、孤独、归属感...

  对每个情绪事件，描述：
  - 触发情境
  - 情绪表现（外在的和内在的）
  - 此人如何处理/消化了这个情绪
  - 这个情绪经历是否影响了后续的决策或关系
```

### 4D：目标与计划的演变

```yaml
prompt: |
  追踪 {character} 一生中的目标体系演变：

  在每个主要人生阶段：
  - 此人的核心长期目标是什么？
  - 为实现长期目标制定了哪些中期计划？
  - 哪些目标实现了？哪些被放弃了？哪些被修改了？
  - 新目标是如何产生的？（来自成功?失败?外部变化?内心觉醒?）
```

## Phase 5的一个关键设计：合并和转换

原始提取出来的是碎片化的事件/动作列表。你需要一个转换步骤把它们变成训练数据格式：

```yaml
conversion_prompt: |
  将以下关于 {character} 的事件描述，转换为 belief-observation-action 格式：

  原始事件：{raw_event}

  当时的人物背景：{context_from_phase1}

  请输出：
  belief: 
    self_identity: (此刻此人认为自己是谁，处于什么角色)
    goals: (当前的目标，长期和短期)
    knowledge: (此人当时知道什么、相信什么，包括可能的错误信念)
    emotional_state: (当前情绪)
    relationships: (与当前事件相关的人际关系状态)
  
  observation: (此人此刻观察/接收到了什么新信息)

  action:
    internal_actions: (思考、判断、情绪变化、目标更新、记忆整理等)
    external_actions: (说了什么、做了什么可观察的行为)
    reasoning: (连接observation到action的简要推理)
```

## 关于管线效率的实际建议

### 并行与缓存

```python
# 伪代码架构
for character in characters:
    meta = extract_meta(character)          # Phase 0
    timeline = extract_timeline(character)   # Phase 1
  
    # Phase 2: 交叉枚举 —— 高度可并行
    raw_actions = []
    for stage in timeline.stages:
        for domain in meta.domains:
            raw_actions += cross_extract(character, stage, domain, "domain")  # 2A
        for person in meta.relationships:
            raw_actions += cross_extract(character, stage, person, "relationship")  # 2B
        for role in meta.roles:
            raw_actions += cross_extract(character, stage, role, "role")  # 2C
  
    # Phase 3: 长尾 —— 用已提取内容作为排除列表
    exclusion = summarize(raw_actions)
    raw_actions += long_tail_extract(character, exclusion)  # 3A-3D
  
    # Phase 4: 内部动作 —— 可以基于Phase 2/3的输出精准追问
    for action in raw_actions.filter(is_major_decision):
        internal = extract_internal(character, action)  # 4A-4D
        action.enrich(internal)
  
    # Phase 5: 格式转换
    training_samples = convert_to_boa_format(character, meta, raw_actions)
```

### 质量控制

每一步之后加一个轻量的验证步骤：

```yaml
validation_prompt: |
  以下关于 {character} 的描述，请标注每条的可信度：
  A: 有明确历史/原著依据
  B: 合理推断，符合人物逻辑
  C: 可能是编造/张冠李戴

  {extracted_items}
```

对于虚构人物，B类可以大胆保留；对于真实人物，C类需要谨慎处理。

### 一个容易忽视的问题：不同角色的密度差异

```
拿破仑  → LLM知识极其丰富，可能提取出500+动作
路人甲配角 → 可能只有20个动作
```

你需要对不同密度的角色采用不同深度的管线。可以在Phase 0之后加一个分流：

```python
if meta.knowledge_density == "rich":    # 拿破仑、曹操
    run_full_pipeline()                  # 所有Phase全跑
elif meta.knowledge_density == "medium": # 次要历史人物
    run_phases(0, 1, 2A, 3D, 4B, 5)    # 跳过部分交叉
elif meta.knowledge_density == "sparse": # 配角/小众角色
    run_phases(0, 1, "condensed_2", 5)  # 压缩版提取
```

---

这整套管线的本质是：**用结构化的多维度交叉枚举，系统性地对抗LLM的显著性偏差，把长尾知识逼出来**。单独任何一个维度都会很快撞上重复墙，但交叉之后组合空间足够大，能把模型关于一个人物的知识榨得相当干净。
