# 美国漫画

## 漫威（Marvel）

### 复仇者联盟核心
- Tony Stark / Iron Man（托尼·斯塔克 / 钢铁侠）— 花花公子天才发明家，方舟反应堆在胸口
- Steve Rogers / Captain America（史蒂夫·罗杰斯 / 美国队长）— 超级士兵血清，"I can do this all day"
- Thor Odinson（索尔·奥丁森）— 雷神，米奥尔尼尔，"Whosoever holds this hammer..."
- Bruce Banner / Hulk（布鲁斯·班纳 / 浩克）— 愤怒的绿色巨人，"Hulk SMASH!"
- Natasha Romanoff / Black Widow（黑寡妇）— 红房训练的前俄国间谍
- Clint Barton / Hawkeye（鹰眼）— 弓箭手

### X战警
- Logan / Wolverine（金刚狼）— 治愈因子，艾德曼金属骨架，金刚爪，"I'm the best there is at what I do"
- Charles Xavier / Professor X（X教授）— 泽维尔天赋少年学校校长，心灵感应
- Erik Lehnsherr / Magneto（万磁王）— 大屠杀幸存者，磁力操控，变种人至上
- Jean Grey / Phoenix（琴·葛蕾 / 凤凰）— 欧米茄级变种人，凤凰之力宿主
- Scott Summers / Cyclops（镭射眼）— X战警队长
- Rogue（小淘气）— 接触吸收能力
- Storm / Ororo Munroe（暴风女）— 操控天气
- Mystique（魔形女）— 变形
- Deadpool / Wade Wilson（死侍）— 打破第四面墙的雇佣兵，"Maximum effort!"
- Cable（电索）— 来自未来的机械臂战士
- Psylocke（灵蝶）— 精神能量刃

### 蜘蛛侠相关
- Peter Parker / Spider-Man（彼得·帕克 / 蜘蛛侠）— "With great power comes great responsibility"
- Mary Jane Watson（MJ）— 彼得之妻
- Gwen Stacy（格温·斯泰西）— 被绿魔害死的第一任女友，蜘蛛格温（Earth-65）
- Miles Morales（迈尔斯·莫拉莱斯）— 终极宇宙的二代蜘蛛侠
- Venom / Eddie Brock（毒液）— 共生体，反英雄
- Carnage / Cletus Kasady（屠杀）— 毒液的儿子
- Green Goblin / Norman Osborn（绿魔）— 奥斯本工业
- Doctor Octopus / Doc Ock（章鱼博士）— 机械触手

### 其他漫威
- T'Challa / Black Panther（黑豹）— 瓦坎达国王
- Carol Danvers / Captain Marvel（惊奇队长）
- Stephen Strange / Doctor Strange（奇异博士）— 至尊法师
- Matt Murdock / Daredevil（夜魔侠）— 盲人律师，雷达感
- Frank Castle / The Punisher（惩罚者）— 以暴制暴
- Thanos（灭霸）— 收集无限宝石求死亡女神之爱
- Galactus（行星吞噬者）— 吞食星球的宇宙存在，"I am Galactus, the devourer of worlds"
- Silver Surfer / Norrin Radd（银色冲浪者）— Galactus 的使者

## DC

### 正义联盟
- Kal-El / Clark Kent / Superman（超人）— 氪星最后之子，大都会，路易斯·莱恩
- Bruce Wayne / Batman（布鲁斯·韦恩 / 蝙蝠侠）— 哥谭的暗夜侦探，不杀原则，"I am vengeance, I am the night, I am Batman!"
- Diana Prince / Wonder Woman（神奇女侠）— 亚马逊公主，真言套索
- Barry Allen / The Flash（闪电侠）— 神速力
- Hal Jordan / Green Lantern（绿灯侠）— 2814扇区，意志力戒指
- Arthur Curry / Aquaman（海王）— 亚特兰蒂斯之王
- Victor Stone / Cyborg（钢骨）

### 蝙蝠侠家族与反派
- Dick Grayson / Nightwing（夜翼）— 第一代罗宾，独立
- Jason Todd / Red Hood（红头罩）— 被小丑杀死后复活复仇的第二代罗宾
- Barbara Gordon / Batgirl / Oracle（蝙蝠女）— 被小丑枪击瘫痪后成为黑客 Oracle
- Damian Wayne— 蝙蝠侠与 Talia al Ghul 之子，第五代罗宾
- Robin— 蝙蝠侠与 Talia al Ghul 之子，第五代罗宾
- The Joker（小丑）— 混乱的化身，化学池
- Harley Quinn（哈莉·奎茵）— 前阿卡姆精神病学家，失足成小丑女伴
- Selina Kyle / Catwoman（猫女）— 亦敌亦情的窃贼
- Two-Face / Harvey Dent（双面人）— 被毁容后以硬币行事
- Scarecrow / Jonathan Crane（稻草人）— 恐惧毒气
- Riddler / Edward Nygma（谜语人）
- Bane（贝恩）— 折断蝙蝠侠脊柱
- Ra's al Ghul（拉斯·奥·古）— 刺客联盟首领，拉撒路之池
- Alfred Pennyworth（阿尔弗雷德）— 韦恩家的管家

### 其他DC
- Joker — 见上
- Lex Luthor（莱克斯·卢瑟）— 超人的宿敌，以人类的才智
- Darkseid（达克赛德）— 反生命方程式
- John Constantine（康斯坦丁）— 地狱神探，黑暗正义联盟
- Shazam / Billy Batson（沙赞）— 喊"沙赞"变身的少年

## 独立漫画与图像漫画
- Spawn / Al Simmons（再生侠 / 艾尔·西蒙斯）— Todd McFarlane 创作，前 CIA 特工，被烧死进入地狱后与恶魔签约
- Hellboy（地狱男爵）— Mike Mignola，从地狱召唤来的婴儿被收养，超自然现象调查防御署（B.P.R.D.）
- Abe Sapien（鱼人亚伯）— 《地狱男爵》的伙伴
- The Walking Dead（行尸走肉）— Robert Kirkman，Rick Grimes 警官在丧尸末日保护家人，"We are the walking dead"
- Michonne（米琼恩）— 《行尸走肉》，刀女
- Negan（尼根）— Lucille（缠铁丝棒球棍）
- Invincible / Mark Grayson（无敌少侠）— Robert Kirkman，超级英雄少年发现父亲 Nolan（Omni-Man）是入侵地球的 Viltrumite
