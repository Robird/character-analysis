# 日本游戏 · 任天堂经典

## 超级马力欧系列（Super Mario，宫本茂，1985起）
- Mario（マリオ / 马力欧）— 红衣水管工，蘑菇王国的英雄，"It's-a me, Mario!"
- Luigi（ルイージ / 路易吉）— 绿衣弟弟，比哥哥高但胆小
- Peach（ピーチ姫 / 碧琪公主）— 蘑菇王国的公主，频繁"在另一座城堡"
- Bowser（クッパ / 库巴）— 龟壳魔王，不断绑架公主的火焰吐息大魔王
- Yoshi（ヨッシー / 耀西）— 绿色小恐龙，好吃的舌头
- Toad（キノピオ / 奇诺比奥）— 蘑菇头忠臣
- Rosalina（ロゼッタ / 罗莎塔）— 《超级马力欧银河》，彗星天文台的守护者与星之子
- Wario（ワリオ）— 马力欧的贪婪反面，大蒜超人
- Waluigi（ワルイージ）— 路易吉的瘦高反派版
- Donkey Kong（ドンキーコング / 大金刚）— 打领带的大猩猩
- Diddy Kong — 大金刚的小搭档

## 塞尔达传说系列（The Legend of Zelda，宫本茂/青沼英二，1986起）
- Link（リンク / 林克）— 海拉尔勇者，三角力量之勇气，沉默的绿衣精灵少年
- Zelda（ゼルダ / 塞尔达公主）— 海拉尔公主，三角力量之智慧，Sheik 变装
- Ganon / Ganondorf（ガノン / 加农多洛夫）— 格鲁德族的魔王，三角力量之力
- Impa（インパ）— 塞尔达的希卡族守护者
- Epona（エポナ）— 林克的马
- Navi（ナビィ）— 《时之笛》，"Hey! Listen!" 的精灵
- Midna（ミドナ）— 《黄昏公主》，小恶魔形态的黄昏公主
- Fi（ファイ）— 《天空之剑》，女神之剑的剑灵
- Tingle（チンクル）— 穿紧身连体衣的35岁大叔妖精
- 四英杰 — 《旷野之息》：Mipha（米法 / 卓拉），Revali（力巴尔 / 利特），Daruk（达尔克尔 / 鼓隆），Urbosa（乌尔波扎 / 格鲁德）
- 古代守护者 — 《旷野之息》，以激光瞄准的白垩纪噩梦

## 宝可梦系列（Pokémon / ポケットモンスター，田尻智，1996起）
- サトシ（小智 / Ash Ketchum）— 来自真新镇，梦想成为宝可梦大师，"ゲットだぜ！"
- ピカチュウ（皮卡丘）— 电气鼠，拒绝进入精灵球
- ロケット団（火箭队）— ムサシ（武藏）·コジロウ（小次郎）·ニャース（喵喵），"やな感じ～"
- ミュウツー（超梦）— 基因改造的最强宝可梦，"我是谁？"
- レッド（Red / 赤红）— 初代游戏主角，白银山顶的传说
- 御三家 — 历代火/水/草初始宝可梦
- 伝説のポケモン — Mew, Lugia, Ho-Oh, Rayquaza, Arceus 等

## 密特罗德系列（Metroid，1986起）
- Samus Aran（サムス·アラン / 萨姆斯·阿兰）— 银河最强的赏金猎人，装甲中首次揭露为女性
- Ridley（リドリー / 利德雷）— 宇宙海贼的首领，杀死萨姆斯双亲的太空龙
- Metroid（メトロイド）— 吸取生命能量的浮游水母生物

## 星之卡比系列（Kirby，樱井政博，1992起）
- Kirby（カービィ / 卡比）— 粉色圆球，吸入敌人后复制能力，"噗哟！"
- Meta Knight（メタナイト）— 戴面具的剑客，有时敌有时友
- King Dedede（デデデ大王）— 企鹅模样的自封大王，拿着大锤

## 火焰纹章系列（Fire Emblem，1990起）
- Marth（マルス / 马尔斯）— 《暗黑龙与光之剑》的王子，大乱斗常客
- Ike（アイク）— 《苍炎之轨迹》的佣兵
- Lucina（ルキナ）— 《觉醒》，穿越时间改变命运的女剑士
- Chrom（クロム）— 《觉醒》，伊利斯圣王国王子
- Edelgard / Dimitri / Claude — 《风花雪月》，三学级的级长

## 异度系列（Xeno，高桥哲哉）
- Shulk（シュルク）— 《异度之刃》，持有未来视的莫纳德少年
- Pyra / Mythra（ホムラ / ヒカリ）— 《异度之刃2》，天之圣杯的双人格
- Rex（レックス）— 《异度之刃2》，打捞员少年

## 其他任天堂系
- Captain Falcon（キャプテン·ファルコン）— 《F-ZERO》，"Falcon Punch!"

- Inklings（インクリング）— 《Splatoon》（喷射战士），变身乌贼的少年

- Wii Fit Trainer — 《大乱斗》看板角色
