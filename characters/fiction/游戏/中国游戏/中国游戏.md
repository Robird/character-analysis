# 中国游戏

## 仙剑奇侠传系列（大宇资讯，1995起）

- 赵灵儿 — 女娲后裔，仙灵岛的池中莲花少女，"既不回头，何必不忘"
- 林月如 — 苏州林家堡大小姐，比武招亲，锁妖塔
- 阿奴 — 苗疆少女
- 景天 / 雪见 / 龙葵 — 《仙剑奇侠传三》
- 韩菱纱 / 云天河 / 慕容紫英 — 《仙剑奇侠传四》，"承君此诺，必守一生"

## 原神（Genshin Impact / 原神，米哈游，2020起）
- 空 / 荧（双子旅行者）— 跨越星海寻找失散手足的异界来客
- 派蒙 — 应急食品（?），旅行者的向导
- 温迪（Venti / 巴巴托斯）— 蒙德的吟游诗人风神，"诶嘿"
- 钟离（Zhongli / 摩拉克斯）— 往生堂客卿，岩王帝君的退休生活，"欲买桂花同载酒"
- 雷电将军（Raiden Shogun / 巴尔）— 稻妻的女武神，永恒之国的孤独
- 纳西妲（Nahida / 布耶尔）— 须弥的草神，被囚五百年
- 芙宁娜（Furina / 芙卡洛斯）— 枫丹的假水神
- 公子（达达利亚 / Tartaglia）— 愚人众执行官，双刀与水之刃的战斗狂
