# 拉丁美洲电影

## 墨西哥
- Octavio / Susana / El Chivo — Alejandro González Iñárritu《爱情是狗娘》（Amores perros，2000），一场车祸连接三段命运
- Cristian / Cristina / El Chino — Iñárritu《通天塔》（Babel，2006），多国多线叙事中的墨西哥部分
- Julio / Tenoch / Luisa — Alfonso Cuarón《你妈妈也一样》（Y tu mamá también，2001），墨西哥少年的公路启蒙
- Cleo（克莱奥）— Alfonso Cuarón《罗马》（Roma，2018），1970年代墨西哥城的土著女佣
- Ofelia（奥菲莉娅）— Guillermo del Toro《潘神的迷宫》（El laberinto del fauno，2006），西班牙内战后的童话与现实交错，农牧神 Fauno、苍白之人 Pale Man
- Fauno（农牧神）— 《潘神的迷宫》
- 苍白之人（Pale Man）— 《潘神的迷宫》，以手掌上的眼睛追逐奥菲莉娅
- Padre Karras — 《驱魔人》（1973），并非拉丁美洲电影，但 Del Toro 的风格继承

## 巴西
- Buscapé（火箭）— Fernando Meirelles / Kátia Lund《上帝之城》（Cidade de Deus，2002），里约贫民窟的摄影少年
- Zé Pequeno（小霸王）— 《上帝之城》，冷酷的毒贩
- Bené（班尼）— 《上帝之城》，Zé Pequeno 的帅气搭档
- Dora（朵拉）— Walter Salles《中央车站》（Central do Brasil，1998），写信的老妇人与流浪男孩在巴西内陆的旅程
- Josué — 《中央车站》，寻找父亲的男孩
- Maicon / Jeferson / Criolo — 《精英部队》（Tropa de Elite，2007/2010），里约 BOPE 特警队长 Capitão Nascimento，"Pede pra sair!"

## 阿根廷
- Juan / Zavaleta / Arocena — 《九个皇后》（Nueve reinas，2000），布宜诺斯艾利斯的骗子兄弟
- Ernesto Guevara / Alberto Granado — Walter Salles《摩托日记》（Diarios de motocicleta，2004），年轻的切·格瓦拉穿越南美
- 六故事 — 《荒蛮故事》（Relatos salvajes，2014），以暴力报复为主题的黑色喜剧

## 智利
- 广告天才 — Pablo Larraín《智利说不》（No，2012），以广告推翻皮诺切特的公投
- 修女 — 《神父俱乐部》（El club，2015），被教廷流放的神父们的暗黑忏悔

## 哥伦比亚
- 《蛇之拥抱》（El abrazo de la serpiente，2015），亚马逊原住民 Karamakate 与两代白人科学家

## 古巴
- 钢琴师 — 《草莓与巧克力》（Fresa y chocolate，1993）
