# 日本文学

## 古典文学

### 《源氏物語》（紫式部，11世纪初）
- 光源氏（ひかるげんじ）— 桐壺帝皇子，降为臣籍，绝世美男，一生与众多女性纠缠
- 紫の上（むらさきのうえ）— 源氏亲手养大的理想女性，终非正室
- 藤壺の女御 — 桐壺帝的妃子，源氏的初恋（生母般的禁忌之恋）
- 葵の上（あおいのうえ）— 源氏正妻，被六条御息所的生灵所害
- 六条御息所（ろくじょうのみやすどころ）— 源氏的情人，因嫉妒化为生灵
- 明石の君 — 源氏流放须磨时结识，其女后成为皇后
- 女三の宮 — 源氏晚年再娶的年轻正妻，与柏木私通生下薰
- 薫（かおる）— 名义上源氏之子（实为柏木之子），《宇治十帖》的主角
- 浮舟（うきふね）— 薫与匂宮之间摇摆不定，最终投水获救后出家

### 《平家物語》（13世纪，军记物语）
- 平清盛（たいらのきよもり）— 平氏权力巅峰，"非平氏者皆非人"
- 平敦盛（たいらのあつもり）— 十七岁的年轻武士，被熊谷直实所杀
- 源義経（みなもとのよしつね）— 军事天才，功高震主被兄赖朝追杀
- 静御前（しずかごぜん）— 义经的爱妾白拍子

### 《枕草子》（清少納言，11世纪）
- 清少納言本人以第一人称叙述宫廷见闻，非虚构人物

### 《方丈記》《徒然草》— 随笔，角色较少

## 近代文学（明治·大正·昭和前期）

### 夏目漱石（なつめ そうせき）
- 主人公（猫）— 《吾輩は猫である》（我是猫），无名猫，以猫眼观察人类
- 苦沙弥先生 — 《我是猫》，猫的主人，迂阔的中学教师
- 坊っちゃん（少爷）— 《坊っちゃん》，东京到松山的耿直青年教师
- 「先生」（Sensei）— 《こころ》（心），背负对友人K的愧疚而自杀的孤独者
- K — 《心》，被先生以道德逼死的友人

### 森鷗外
- 太田豊太郎 — 《舞姫》，在德国与舞女艾莉丝相恋的日本留学生
- エリス（艾莉丝）— 《舞姫》，怀孕后被抛弃的德国舞女

### 芥川龍之介
- 下人 — 《羅生門》，在饿死与为盗之间的道德选择
- 禅智内供 — 《鼻》，为过长鼻子的自卑所苦的僧人
- 多襄丸 / 武弘 / 真砂 — 《藪の中》（竹林中），同一事件三个相互矛盾的版本（黑泽明《罗生门》的原作）
- 良秀 — 《地獄変》，为艺术眼看女儿被烧死的画师

### 谷崎潤一郎
- 春琴 / 佐助 — 《春琴抄》，盲女琴师与刺瞎自己双目的仆人
- 蒔岡家四姐妹 — 《細雪》，大阪没落望族的四姐妹
- 譲治 / ナオミ — 《痴人の愛》，被少女操控的中年男

### 川端康成（诺贝尔文学奖）
- 島村 / 駒子 — 《雪国》，来自东京的虚无文人岛村与雪国艺伎驹子
- 葉子 — 《雪国》，驹子之妹（或另一面），在火灾中坠落而死
- 菊治 — 《千羽鶴》，茶道之美与乱伦之阴影
- 太田夫人 / 文子 — 《千羽鶴》

### 三島由紀夫
- 溝口 — 《金閣寺》，口吃丑陋的年轻僧人，以火烧金阁寺完成自我
- 松枝清顕 / 本多繁邦 — 《豊饒の海》四部曲，轮回与见证
- 安永透 — 《午後の曳航》，以13岁少年的视角解构成人世界的虚伪

### 太宰治
- 大庭葉蔵（Yozo）— 《人間失格》，戴上小丑面具活着的自毁者
- かず子 — 《斜陽》，没落贵族的女儿

### 志賀直哉
- 「私」— 《暗夜行路》，与父冲突和解

### 樋口一葉
- 美登利 — 《たけくらべ》（比肩），吉原花街的少女在成年边缘

### 宮沢賢治
- ジョバンニ / カムパネルラ — 《銀河鉄道の夜》，少年与挚友的银河之旅
