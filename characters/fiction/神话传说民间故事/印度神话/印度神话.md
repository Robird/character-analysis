# 印度神话

## 三相神（Trimūrti）
- Brahmā（ब्रह्मा，梵天）— 创造之神，四面四臂，坐于莲花
- Viṣṇu（विष्णु，毗湿奴）— 维护与保护之神，慈悲化身，以十大化身下凡救世
  - Matsya（鱼）— 第一个化身，从大洪水中拯救人类
  - Kūrma（龟）— 搅乳海（Samudra Manthan）时背负曼荼罗山
  - Varāha（野猪）— 将沉入海底的大地女神 Bhudevi 托出水面
  - Narasiṃha（人狮）— 半人半狮，杀死魔王 Hiraṇyakaśipu
  - Vāmana（侏儒）— 三步跨越三界，降服魔王 Bali
  - Paraśurāma（持斧罗摩）— 消灭傲慢的刹帝利
  - Rāma（罗摩）— 《罗摩衍那》主角，理想君王，毗湿奴最重要化身之一
  - Kṛṣṇa（克里希那 / 黑天）— 牧童、战车御者、神性爱人，《摩诃婆罗多》中传授《薄伽梵歌》
  - Buddha（佛陀）— 有些传统中列为第九化身
  - Kalki（迦尔基）— 末世化身，骑白马，持烈火剑
- Śiva（शिव，湿婆）— 毁灭与再生之神，瑜伽之主，舞蹈之神（Nataraja），第三眼

## 女神（Devī）
- Sarasvatī（सरस्वती，辩才天女）— 知识、音乐与艺术女神，梵天的配偶
- Lakṣmī（लक्ष्मी，吉祥天女）— 财富、繁荣与美丽女神，毗湿奴之妻
- Pārvatī（पार्वती，雪山神女）— 湿婆之妻，温和形态，Ganesha 与 Kārtikeya 之母
- Durgā（दुर्गा，杜尔迦）— 帕尔瓦蒂的战神形态，骑狮，十臂，杀水牛魔王 Mahiṣāsura
- Kālī（काली，迦梨）— 帕尔瓦蒂的愤怒毁灭形态，黑色，戴骷髅项链
- Sītā（सीता，悉多）— 罗摩之妻，贞洁与美德的化身，被魔王 Rāvaṇa 掳走
- Rādhā（राधा，罗陀）— 克里希那的至爱与伴侣，神圣爱欲的象征

## 其他重要神祇
- Indra（इन्द्र，因陀罗）— 天神之王，雷雨之神，金刚杵（Vajra）持有者
- Agni（अग्नि，阿耆尼）— 火神，祭祀的媒介
- Sūrya（सूर्य，苏利耶）— 太阳神
- Vāyu（वायु，风神伐由）— 风神
- Varuṇa（वरुण，伐楼那）— 水与宇宙秩序之神
- Yama（यम，阎魔）— 死神，冥界之王，第一位死去的人类
- Kubera（कुबेर，俱毗罗）— 财富之神，夜叉之王
- Gaṇeśa（गणेश，象头神 / 格涅沙）— 智慧与障碍清除之神，湿婆与帕尔瓦蒂之子，象头
- Kārtikeya / Skanda / Murugan（迦絺吉夜 / 室建陀）— 战神，湿婆次子，孔雀坐骑
- Hanumān（हनुमान，哈奴曼）— 猴神，罗摩的忠实追随者，风神之子，《罗摩衍那》中飞跃渡海
- Garuḍa（गरुड，迦楼罗 / 大鹏金翅鸟）— 鸟王，毗湿奴的坐骑，蛇类的死敌
- Nāga（नाग，那伽）— 蛇神，水中的半神
- Apsaras（अप्सरा，天女）— 天上的舞者与诱惑女神

## 《摩诃婆罗多》关键人物
- Yudhiṣṭhira（坚战）— 五王子之首，正义化身
- Bhīma（怖军）— 五王子之二，力大无穷
- Arjuna（अर्जुन，阿周那）— 五王子之三，神射手，克里希那的挚友与《薄伽梵歌》的聆听者
- Nakula（无种）— 五王子之四，美男子
- Sahadeva（偕天）— 五王子之五，智慧者
- Draupadī（द्रौपदी，黑公主）— 五王子共妻，被当众羞辱，引发大战
- Kṛṣṇa（克里希那）— 作为阿周那的御者与导师
- Bhīṣma（毗湿摩）— 可怖誓言者，百子与五子共同的祖父辈
- Droṇa（德罗纳）— 五王子与百子的武艺老师
- Karṇa（迦尔纳）— 太阳神之子，百子一方的英雄，悲剧人物
- Duryodhana（难敌）— 百子之首，大战的主要反派
- Śakuni（沙恭尼）— 难敌的舅舅，掷骰子骗局的设计者

## 《罗摩衍那》关键人物
- Rāma（राम，罗摩）— 阿逾陀王子，被流放森林十四年，救回悉多
- Sītā（悉多）— 罗摩之妻
- Lakṣmaṇa（罗什曼那）— 罗摩之弟，伴随流放
- Bharata（婆罗多）— 罗摩之弟，以罗摩的鞋代为治国十四年
- Rāvaṇa（罗波那）— 十首魔王，楞伽（兰卡）之王，掳走悉多
- Hanumān（哈奴曼）— 猴神，罗摩的使者
- Jatāyu（阇吒优私）— 神鹫，为救悉多与罗波那搏斗牺牲
- Śūrpaṇakhā（首哩薄那迦）— 罗波那的妹妹，因被罗什曼那割鼻而引发战争
