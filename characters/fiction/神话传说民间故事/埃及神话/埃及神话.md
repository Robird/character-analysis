# 埃及神话

## 九柱神（Heliopolis Ennead）
- Ra / Re（拉）— 太阳神，创世主，白天乘太阳船航行天空，夜晚穿行冥界
- Atum（阿图姆）— 原始创世神，自生于混沌之水 Nun
- Shu（舒）— 空气与干燥之神，分开天与地
- Tefnut（泰芙努特）— 湿气女神，舒的姐妹与配偶
- Geb（盖布）— 大地之神
- Nut（努特）— 天空女神，盖布之妻，身体覆盖大地
- Osiris（奥西里斯 / Usir）— 冥界之王，复活与农业之神，被弟弟塞特杀害分尸
- Isis（伊西斯 / Aset）— 魔法、母性与治愈女神，奥西里斯之妻，收集丈夫碎片并用魔法复活
- Set / Seth（塞特）— 混乱、沙漠与风暴之神，杀兄奥西里斯
- Nephthys（奈芙蒂斯 / Nebet-Het）— 死者与丧葬女神，塞特之妻

## 重要神祇
- Horus（荷鲁斯 / Heru）— 鹰头神，奥西里斯与伊西斯之子，为父复仇，法老的守护神，荷鲁斯之眼（Wedjat）象征保护
- Anubis（阿努比斯 / Anpu）— 胡狼头神，木乃伊制作与葬礼之神，死者心脏称重
- Thoth（托特 / Djehuty）— 鹮头神，智慧、书写与魔法之神
- Hathor（哈索尔 / Hwt-Her）— 爱、音乐、美丽与欢乐的女神，牛头或牛耳
- Bastet（芭丝特）— 猫女神，家庭、生育与保护（原为狮女神塞赫麦特的温和形态）
- Sekhmet（塞赫麦特）— 狮头战争与瘟疫女神，拉派去惩罚人类的烈怒之眼
- Ptah（普塔）— 孟菲斯造物神，工匠与建筑师的保护者
- Ma'at（玛亚特）— 真理、正义与宇宙秩序的女神，亡灵审判的核心
- Amun（阿蒙）— 底比斯主神，后与拉合成 Amun-Ra，新王国时期众神之王
- Sobek（索贝克）— 鳄鱼神，尼罗河与法老的力量
- Bes（贝斯）— 侏儒神，家庭的保护者，驱邪
- Taweret（塔沃里特）— 河马女神，保护孕妇与分娩
- Khnum（克努姆）— 公羊头神，以陶轮造人，尼罗河源头之神
- Apophis / Apep（阿波菲斯）— 混沌巨蛇，拉的宿敌，每日试图吞噬太阳船

## 法老（被神化或与神话紧密关联）
- Narmer（纳尔迈 / Menes）— 统一上下埃及，常与神话始祖关联
- Djoser（左塞尔）— 法老神化与阶梯金字塔
- Ramesses II（拉美西斯二世）— 自封为神圣君王，神庙遍布
- Akhenaten（阿肯那顿）— 推行阿吞（Aten）一神崇拜，图坦卡蒙之父

## 神话生物与符号
- Sphinx（狮身人面像）— 法老守护者
- Phoenix（贝努鸟 / Bennu）— 与拉和复活相关的不死鸟
- 圣甲虫（Khepri）— 太阳升起的象征
- 荷鲁斯之眼（Wedjat）— 保护与健康的象征
- Ankh（安卡）— 生命之符
