# 两河流域神话

## 苏美尔神系
- An / Anu（安 / 安努）— 天神，众神之父（苏美尔/阿卡德）
- Enlil（恩利尔）— 风与大气之神，众神之王，尼普尔的主神
- Enki / Ea（恩基 / 埃阿）— 智慧、水与创造之神，人类的朋友，埃利都的主神
- Ninhursag / Nintu（宁胡尔萨格）— 大地母神，生育女神，恩基的配偶
- Inanna（伊南娜）— 爱、性与战争女神（苏美尔名），金星女神，乌鲁克主神
- Ištar（伊什塔尔）— 伊南娜的阿卡德名，巴比伦时期的主要女神
- Utu / Šamaš（乌图 / 沙马什）— 太阳神，正义之神
- Nanna / Sîn（南纳 / 辛）— 月亮神，乌尔的主神
- Ereshkigal（埃列什基伽勒）— 冥界女王，伊南娜的姐姐
- Nergal（内尔伽勒）— 战争、瘟疫与冥界之神，后成为埃列什基伽勒的配偶
- Ninurta（尼努尔塔）— 战神、狩猎神、农业神
- Dumuzi / Tammuz（杜木兹 / 塔穆兹）— 牧神，伊南娜的情人，每年死亡与复活
- Enkimdu（恩基姆杜）— 农神
- Ningirsu（宁吉尔苏）— 拉加什的守护神，与尼努尔塔常混同

## 巴比伦神系与创世神话
- Marduk（马尔杜克）— 巴比伦主神，斩杀提亚马特创世，《埃努玛·埃利什》（Enûma Eliš）的主角
- Tiamat（提亚马特）— 原初混沌的咸水女神，巨龙形态，被马尔杜克斩杀后以其身体创造天地
- Apsû（阿普苏）— 原初淡水的象征，提亚马特的配偶，被埃阿所杀
- Qingu（金古）— 提亚马特的将领，其血液被用来创造人类
- Nabû（那布）— 书写与智慧之神，马尔杜克之子
- Aššur（亚述尔）— 亚述帝国的国家神，等同于恩利尔

## 史诗与英雄
- Gilgameš（吉尔伽美什 / 𒄑𒂆𒈦）— 乌鲁克王，半神，《吉尔伽美什史诗》主角，追求永生而不得
- Enkidu（恩奇都）— 野人，众神创造来制衡吉尔伽美什，后成为其挚友
- Utnapištim（乌特纳皮什提姆）— 大洪水的幸存者，被赐永生，对应圣经挪亚，苏美尔称 Ziusudra
- Ḫumbaba / Huwawa（洪巴巴）— 雪松林的守护怪物，被吉尔伽美什与恩奇都杀死
- Gugalanna / 天之公牛（Bull of Heaven）— 被吉尔伽美什与恩奇都杀死
- Adapa（阿达帕）— 智者，被埃阿赋予智慧却因拒绝了永生的食物而返回人间
- Etana（埃塔纳）— 基什王，骑鹰上天寻找生育之草
- Lugalbanda（卢加尔班达）— 乌鲁克王，吉尔伽美什之父，在史诗中也有单独传说

## 伊南娜/伊什塔尔相关
- 伊南娜下冥界（Inanna's Descent to the Underworld）— 经过七重门被剥光并被杀，后被复活
- Dumuzi 的死亡 — 伊南娜归来后发现情人在享乐，将他送下冥界替代自己

## 其他重要形象
- Lamassu / Shedu（拉玛苏 / 舍杜）— 人首有翼公牛/狮子，宫殿与城市守护者
- Apkallu（阿普卡卢）— 半人半鱼的七贤者，为人类带来文明知识
