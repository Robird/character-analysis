# 东南亚神话

## 印度化的东南亚主要神祇与形象
- Garuda（เกรุฑ / គ្រុឌ / Garuda）— 大鹏金翅鸟，毗湿奴的座驾，在泰国和印尼为国徽，鹰头人身
- Nāga（นาค / នាគ / Naga）— 那伽蛇神，水、地下与财富的守护者，湄公河与洞里萨湖的传说中常见
- Hanuman（หนุมาน / ហនុមាន）— 哈奴曼，猴神，泰国《拉玛坚》（Ramakien）中的主要英雄
- Indra（ព្រះឥន្ទ្រ / Phra In）— 因陀罗，天神之王，在东南亚佛教神话中为忉利天之主
- Brahma（ព្រះព្រហ្ម / Phra Phrom）— 梵天，四面佛，泰国四面佛（Erawan Shrine）的崇拜对象
- Yama（យម / Phra Yom）— 阎魔，冥界之王，审判死者
- Rāma（ព្រះរាម / Phra Ram）— 罗摩，《拉玛坚》（泰版罗摩衍那）的英雄主角
- Sītā（នាងសីតា / Nang Sida）— 悉多
- Rāvaṇa / Tosakanth（ទសកណ្ហ / ทศกัณฐ์）— 罗波那，十首魔王

## 东南亚本土神祇与精灵
- Dewi Sri / Phosop / Nang Khosop（稻谷女神）— 稻米女神，在印尼、泰国、柬埔寨等地均有崇拜
- Mae Thorani（แม่ธรณี）— 大地女神，泰国佛教中挣脱头发洪水退魔军
- Phi（ผี）— 泰国泛灵信仰中的鬼魂/精灵
- Nang Tani（นางตานี）— 野生香蕉树中的女精灵
- Phi Krasue（กระสือ）— 飞头女鬼，夜间飘飞觅食
- Khwan（ขวัญ）— 泰国/老挝人身上的灵/魂魄概念
- Phosop / Mae Phosop（แม่โพสพ）— 泰国稻谷女神
- Nang Nak / Mae Nak（แม่นาก）— 泰国最著名的女鬼传说，产后死亡思念丈夫
- Hantu（马来/印尼）— 幽灵、鬼魂的统称
- Pontianak / Kuntilanak（马来/印尼）— 难产而死的女吸血鬼鬼魂，化为美女
- Toyol（马来）— 儿童的邪灵，用于偷窃
- Orang Bunian（马来）— 隐身精灵族
- Nyi Roro Kidul（爪哇）— 南海女王，印度洋女神，绿色为代表色
- Batara Kala（爪哇/巴厘）— 时间与毁灭之神，日食中以 Rahu 吞日月
- Antaboga（爪哇）— 原初的巨蛇，支撑世界
- Barong（巴厘）— 狮形灵兽，与女巫 Rangda 的永恒斗争，象征善
- Rangda（巴厘）— 邪恶的寡妇女巫
- Manimekhala（缅甸/泰国）— 闪电女神，守护海洋
- Thagyamin（缅甸）— 相当于因陀罗的天神，Thadingyut 节与佛陀
