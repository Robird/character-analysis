# 非洲民间故事

## 西非民间故事
- Anansi（阿南西 / Kweku Ananse）— 蜘蛛神/恶作剧者（Trickster），西非最著名的民间传说角色（阿散蒂/加纳），以智慧与诡计对抗强者，也常将故事传给人间
- Nyame（尼阿美）— 阿散蒂神话中的天神，原持有所有故事，后被 Anansi 以豹、蛇等换来
- Asase Yaa（阿萨塞·雅）— 大地女神，尼阿美之妻
- Osebo（豹）— 常在故事中被 Anansi 戏弄的强大动物
- Mmoboro（黄蜂）— Anansi 为换故事而捕捉的动物之一

## 东非民间故事
- Mwindo（姆温多）— 刚果（Nyanga 族）史诗英雄，从母腹中出生即能行走说话，对抗父王与天神的冒险
- Liongo（里翁戈）— 斯瓦希里海岸传说中的英雄、诗人和超自然的勇士，无法被常规武器杀死
- Abunuwasi（阿布努瓦斯）— 斯瓦希里的恶作剧者/智者角色，类似阿拉伯的 Juha / Nasreddin
- Ja'far / Juhā（朱哈 / Nasreddin Hodja）— 横跨中东与非洲的幽默智者与蠢人

## 南非与中部非洲传说
- 螳螂神 / ǀKaggen（卡根）— 桑人（San / Bushmen）创世神话中的恶作剧者与造物主，以螳螂形态出现
- 变色龙与蜥蜴 — 南非创世故事中，变色龙被派往人间传达永生的消息却磨蹭，蜥蜴抢先传达了死亡的消息
- Tikdoshe（提克多西）— 祖鲁传说中的矮小邪恶精灵，以尖牙咬人
- Grootslang（大蛇）— 南非传说中的巨型蛇象混合怪物
- Tokoloshe（托科洛西）— 祖鲁/科萨传说中矮小恶灵
- Kalulu（兔）— 中部非洲的民间故事角色，类似 Brer Rabbit 的机灵兔子

## 马里/桑海史诗
- Sundiata Keita（松迪亚塔·凯塔）— 马里帝国建立者（13世纪），《松迪亚塔史诗》的主角，跛足少年成长为大帝
- Soumaoro Kanté（苏马奥罗·坎特）— 松迪亚塔的宿敌，索索王国的巫师王
- Sogolon（索戈隆）— 松迪亚塔的母亲，水牛女，受嘲笑但坚强的母后

## 尼日利亚/约鲁巴民间故事与宗教
- Eshu / Elegba（埃舒 / 埃莱格巴）— 约鲁巴的恶作剧者与十字路口之神，人与神之间的使者
- Ogun（奥贡）— 铁与战争之神，开辟道路的先驱
- Shango（尚戈）— 雷电之神，约鲁巴历史上的第四位 Alaafin（国王），被神化
- Oshun（奥顺）— 河流、爱情与丰饶女神
- Yemoja（耶莫亚）— 海洋母神，所有河流之母
- Orunmila（奥伦米拉）— 智慧与占卜之神，Ifá 神谕的掌管者
- Ijapa（乌龟）— 约鲁巴民间故事中的典型恶作剧者，类似 Anansi 但以乌龟形象

## 非洲普遍主题
- 动物寓言 — 狮子、豹、大象、乌龟、蜘蛛、兔子、猴子等构成大量道德寓言
- 死亡起源故事 — 各种民族解释人类何以失去永生
- 恶作剧者（Trickster）传统 — 弱小的动物以计谋胜过强大的敌人，是社会批判与智慧的载体
